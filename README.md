# Tic-Tac-Toe with Minimax AI ❌⭕

A classic Tic-Tac-Toe game built with Java, featuring an unbeatable AI opponent utilizing the Minimax algorithm. 

## ✨ Features
* **Unbeatable AI:** The AI evaluates all possible future moves using the Minimax algorithm, ensuring it never loses (it will either win or force a draw).
* **Modern GUI:** Designed with Java Swing, featuring a sleek, responsive dark theme and clear visual feedback for winning moves.
* **Instant Gameplay:** Smooth user experience with slight AI move delays for better natural gameplay feel.

## 🛠️ Technologies Used
* **Language:** Java
* **UI Framework:** Swing (JFrame, JButton, Timer)
* **Algorithm:** Minimax (Game Theory / Artificial Intelligence)

## 🚀 How to Run
1. Clone this repository to your local machine.
2. Compile the Java file via terminal:
   `javac TicTacToe.java`
3. Run the application:
   `java TicTacToe`
